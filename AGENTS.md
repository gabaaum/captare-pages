# Captare Pages

Projeto de landing pages geradas pelo Captare.

## Stack
- HTML5 + CSS3 + JavaScript
- Sem frameworks (puro vanilla)
- Google Fonts (Playfair Display + Inter)

## Padrões de Cores
- Navy: #1a3178
- Navy Dark: #0f1e4a
- Gold: #c9963a
- White: #ffffff

## Estrutura
- Cada pasta contém uma landing page específica
- `index.html` = página principal (Giovanna Paino - Método SOS)
- Imagens e vídeos na raiz ou dentro das pastas

## Regras
- Manter consistência visual entre páginas
- Usar as mesmas fontes e cores definidas
- Otimizar imagens para web
- Manter responsividade mobile
- Seguir padrão de layout split-screen quando aplicável

## Modelos
- **MiMo-V2.5-Pro**: Modelo padrão para este projeto (qualidade máxima)
